# QA → Wiki 反馈回路 + UI 统一设计

> **状态:** 设计稿，待实施
> **目标:** 统一 OpenCodeWiki 的 4 个页面为同一骨架，打通 QA → Wiki 双向反馈

---

## 问题

1. **骨架不统一** — 4 个页面各自渲染，用户每次跳转都面对一套不同的 layout（有的有侧边栏、有的纯内容、有的输入框嵌正文、有的没有输入框）
2. **从 Wiki 到 QA 无入口** — 实体页关联 #Q 只能看标题，不能预览答案，也没有"对此实体提问"的入口
3. **QA 输入框分散** — 首页、Wiki 查看器、QA 页面三套不同的位置和样式
4. **校准归档走旧路径** — 写入 `repo/.codegraph/wiki/qa/`，不走新的 `wiki-page-service`

---

## 设计语言：OpenCodeWiki 是一本书

**核心隐喻：书 + 脚注**

用户来 OpenCodeWiki 是来**阅读和探索**代码知识的，不是来聊天的。所以布局是**书的形态**，而不是对话框的形态。

| 原则 | 含义 |
|------|------|
| **内容优先** | UI 元素不遮盖内容。侧边栏窄（220px），内容区宽。输入框半透明渐变背景。 |
| **上下文不失** | 实体页提问自动带 `#slug`。QA 答案里的 `#` 引用可点击。侧边栏高亮当前位置。 |
| **渐进展开** | 已校准的 #Q 展开，待校准的折叠。文件列表默认短，可展开。不一次性倾倒信息。 |
| **查询即导航** | 底部输入框不只是提问入口，输入实体名、#Q 号时下拉建议引导到对应页面。 |

## 4 个页面定义

### 1. 主页（Home）

**布局:** 变体 A（轻 header，无侧边栏）
**底部输入框:** 通用，placeholder "对代码库提问..."

- Header 只显示 Logo + ⚙️ 管理入口
- 内容区全幅：仓库矩阵（已注册仓库列表 + 快速入口）+ 热门实体 + 最近 #Q
- 点击仓库 → 跳转到该仓库的 Wiki 查看器（实体页，变体 B）
- 无侧边栏，因为主页本身就是导航起点

### 2. 实体页（Entity + Wiki）

**布局:** 变体 B（完整 header + 侧边栏）
**底部输入框:** 上下文感知，placeholder "对「{实体名}」提问..."，自动带 `#slug`

- 侧边栏同时显示 Wiki 模块树 + 实体列表
- 内容区瀑布流（从上到下）:
  ```
  实体名称 + 状态标记
  一句话定义
  涉及代码文件（标签式，可展开）
  Wiki 正文（Markdown 渲染）
  ── 关联问答（最多 5 条）──
  #Q3 如何处理并发？ [已校准 ✅]
  使用连接池 + 异步队列...  [点击展开]
  #Q7 性能瓶颈 [待校准 ⏳]
  主要在 I/O...              [点击展开]
  → 查看全部 N 条关联 #Q
  ```
- 关联 #Q 最多显示 **5 条**，每条只展示 **~80 字摘要**，用户点击展开完整答案
- 超过 5 条的显示 "→ 查看全部 N 条关联 #Q"，链接到 QA 页并带 `?entity={slug}` 参数，新页面打开
- 已校准和待校准的 #Q 显示格式一致（摘要 + 状态标记），区别只在于点击展开后是否能看到完整校准答案
- 点击侧边栏其他 Wiki 页面或实体 → 内容区切换，侧边栏不动

### 3. QA 页（问答）

**布局:** 变体 B（完整 header + 侧边栏）
**底部输入框:** 通用，placeholder "对代码库提问..."

- 侧边栏 #Q 区展示最近 #Q 列表
- 内容区：当前对话（最新 Q&A 会话）+ 历史问答列表
- 每条 #Q 标注实体关联（如 `#问答引擎`）
- 操作：✏️ 校准为标准答案 / 📎 关联到实体

### 4. 管理页（Admin）

**布局:** 变体 B（完整 header + 侧边栏）
**底部输入框:** 隐藏（管理操作不需要提问）

- 侧边栏高亮「⚙️ 管理」，子项：待审区 / 实体管理
- 内容区：待审条目列表 + 校准操作 + 实体状态管理

## QA → Wiki 双向反馈

### 方向 1：Wiki → QA（实体页→提问→校准→归档）

```
用户看实体页 "问答引擎"
  │
  ├── 看到关联 #Q3 的答案已展开，直接可读
  │
  ├── 有问题？底部输入框已带 #qa-engine，提问自动注入上下文
  │   → QA 引擎在 prompt 开头注入 [用户正在查看 "问答引擎 (#qa-engine)"]
  │   → 回答中的 #问答引擎 自动关联到 entity_qa 表
  │
  └── 校准答案 → POST /api/wiki/archive → wiki-page-service 写入
      → 侧边栏 #Q 存档出现条目
      → 侧边栏 Wiki 页面出现归档页面（可选）
```

### 方向 2：QA → Wiki（校准→实体关联→侧边栏可见）

```
QA 页用户校准 #Q3 为标准答案
  │
  ├── 答案写入 calibrated_answers 表
  │
  ├── linkAnswerToEntities() 自动匹配实体 → entity_qa 表
  │
  ├── 用户在实体页刷新 → #Q3 答案展开显示 ✅
  │
  └── 手动归档 → wiki-page-service 写入 qa-archives/
      → 侧边栏 #Q 存档出现
```

## 界面组件

### 统一底部悬浮输入框

```
┌────────────────────────────────────────────┐
│  页面内容（滚动）                            │
│                                            │
│  ── 半透明渐变 ──                           │
│  ┌──────────────────────────────────────┐  │
│  │ 对「问答引擎」提问...  #qa-engine    │  │
│  │                           /bug /log  │  │
│  └──────────────────────────────────────┘  │
│          ↑ position: sticky; bottom: 0     │
└────────────────────────────────────────────┘
```

- `max-width: 640px; margin: 0 auto` 居中
- 圆角 12px + 阴影
- 背景渐变过渡，不遮挡内容
- `/bug`、`/log` 等命令以微型标签显示

**三种状态:**

| 页面 | Placeholder | 上下文 |
|------|------------|--------|
| 主页 | "对代码库提问..." | 无 |
| 实体页 | "对「{实体名}」提问..." | 自动附加 `#slug` |
| QA 页 | "对代码库提问..." | 无 |
| 管理页 | 隐藏 | — |

### 侧边栏

```
📖 Wiki 页面               ← 模块树
  ├ 项目概述               ← 当前高亮蓝色
  ├ 问答引擎
  │  ├ 双路路由
  │  └ 标准答案匹配
  └ 索引系统
────────────────────
🏷️ 实体                    ← 实体列表
  ├ QA Engine (3 个 #Q)
  ├ Token 分词器
  └ 仓储层
────────────────────
💬 #Q 存档                  ← 已校准/已归档
  ├ #Q3: 并发请求处理       ← 点击跳到 QA 页
  ├ #Q7: 性能瓶颈分析
  └ #Q12: 连接池配置
────────────────────
⚙️ 管理                    ← 底部固定
```
