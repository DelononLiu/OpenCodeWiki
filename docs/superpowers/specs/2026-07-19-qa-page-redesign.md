# QA 页面 UI 重构设计

参考：`docs/DocAgent-ui3.html`

## 概述

将 QA 页面从单栏手风琴列表改为三栏聊天布局。
先做 UI（纯前端），后端接口后续对接。

## 布局

```
┌─ Header（不动）─────────────────────────────────────────┐
│                                                          │
│ ┌─Left (w-64)──┐ ┌─Center (flex-1)──────┐ ┌─Right────┐ │
│ │ 关联主题       │ │ ┌─顶栏──────────────┐ │ │ 参考引用  │ │
│ │ #qa-engine    │ │ │ Q 当前问题标题    │ │ │ 代码块   │ │
│ │               │ │ └───────────────────┘ │ │          │ │
│ │ 相关问题       │ │                       │ │ 关联变更  │ │
│ │ · 问题1       │ │  回答块 (hover 显操作) │ │ 代码块   │ │
│ │ · 问题2       │ │  ├ 正文               │ │          │ │
│ │               │ │  ├ 代码引用           │ │          │ │
│ │ 历史对话       │ │  └ 👍 👎 📋 ···      │ │          │ │
│ │ · 对话1       │ │                       │ └──────────┘ │
│ │ · 对话2       │ │ ┌─底部输入框─────────┐ │              │
│ └───────────────┘ │ │ 追问... [发送]     │ │              │
│                    │ └───────────────────┘ │              │
│                    └───────────────────────┘              │
└──────────────────────────────────────────────────────────┘
```

## 三栏结构

### 左栏 (w-64, 可折叠)
- **关联主题** — 静态文本标签 `#qa-engine`
- **相关问题** — 静态占位列表，每项带状态标签（"回答已采纳" / "待验证"），点击行为后续对接
- **历史对话** — 静态占位列表，后续对接 session API
- 折叠按钮（sidebar 图标），点击收起为 0px

### 中栏 (flex-1, 聊天区)
- **顶栏** — 当前问题标题 + 左右栏切换按钮
- **对话区** — 消息时间线（用户消息 + AI 回答块）
  - 用户消息：右对齐蓝色气泡
  - AI 回答块 (`.answer-block`)：正文 + 代码引用 + hover 动作栏
  - 动作栏：👍 有用 / 👎 有误（带 tooltip）+ 📋 复制
  - 反馈后：👍 显示 "已收集反馈" / 👎 触发右栏关联变更 + 标记"未决"
- **底部输入框** — sticky 渐变遮罩 + 输入框 "在此继续追问..." + 发送按钮

### 右栏 (w-[450px], 可折叠)
- **上下堆叠**（不是 tab 切换）
- **参考引用** — 文件名 + 行号 + 代码块
- **关联变更** — 配置文件路径 + 行号 + 代码块
- 折叠按钮

## 需要修改的文件

### 1. `tailwind.config.ts`
- 补 `cyber-orange: '#F59E0B'` 和 `cyber-red: '#EF4444'`

### 2. `QAPage.tsx` — 完全重写
- 状态：`messages` 替代 `qaEntries` 作为主数据结构
- 去掉：`expandedQid`, `followups`, `newQuestionMode`, `showHistory`, `groupByDate`, `formatDate`
- 新增：`leftPanelOpen`, `rightPanelOpen`, `feedbackState`
- 保留：`submitQuestion` (核心提交逻辑), `streamingQuestion`, `streamingAnswer`, `cancelStream`
- 三栏 JSX 布局

### 3. 无需新建文件
- Tooltip 使用 shadcn 已有的 `@/components/ui/tooltip`
- 不需要新建组件文件，QAPage 内部拆几个区域变量即可

## 交互行为

| 操作 | 行为 |
|------|------|
| 中栏底部输入框发送 | 调用 `submitQuestion`，消息追加到时间线 |
| 点击左栏"相关问题"条目 | 切换当前会话到该问题 |
| 点击左栏"历史对话"条目 | 切换当前会话到该对话 |
| hover 回答块 | 显示动作栏 (👍 👎 📋) |
| 点击 👍 | 标记已解决，隐藏操作按钮，显示"已收集反馈" |
| 点击 👎 | 标记未决，展开右栏（如已折叠），关联变更高亮，左侧历史对话对应条目标红 |
| 左右栏折叠按钮 | 切换面板显隐 |

## 不在此 scope 内

- 后端 API 改动（"先搞 UI，再搞后端"）
- 左栏和右栏数据对接真实 API（先用静态占位）
- 反馈持久化（前端 state 即可）
