UI 风格一致性审计结果

当前 5 个页面的 CSS 变量、布局、配色、组件对比

1. CSS 变量名 3 套互不兼容

页面背景色变量边框变量文本色变量
Wiki Viewer--bg--border--text
首页 (Home)var(--surface)var(--border)var(--text)
QA 页面var(--bg-component)var(--color-border)var(--color-text-primary)
实体页 (entity.html)硬编码 #fff硬编码 #e5e7eb硬编码 #1e293b
管理端 (Admin)硬编码 #fff硬编码 #e5e7eb硬编码 #1e293b

2. QA 输入框位置不一致

Wiki Viewer 已经用 position:fixed;bottom:20px;left:50% 实现了底部悬浮。但首页和 QA 页面是内嵌在正文里的，实体页根本没有 QA 输入框。

3. 头部导航不一致

Wiki Viewer 有 sticky header（OpenCodeWiki logo + repo 名称）+ 左侧边栏。实体页只有一个「返回首页」链接。首页和 QA 页各有不同的顶栏组件（user-bar）。

4. 内容区域宽度不一致

Wiki Viewer 正文 max-width:960px（+ 280px 侧边栏），实体页 max-width:800px，管理页 max-width:960px。

建议：统一为 Wiki Viewer 的 CSS 变量体系

因为 Wiki Viewer 是用户交互最多的页面，且变量体系最完整

语义统一变量默认值
背景色--bg#ffffff
次要背景--bg-secondary#f8f9fb
边框--border#e5e7eb
正文色--text#1e293b
次要文本--text-muted#64748b
主题色--primary#2563eb
圆角--radius8px
代码背景--code-bg#f1f5f9

这样统一后，entity.html、admin 页面都能复用同一套变量，不再有"这个页面的蓝色不一样"的问题。
